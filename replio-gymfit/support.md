# Support — Replio GymFit

**App:** Replio GymFit  
**Developer:** Pradap Pandiyan  
**Email:** [support@pradappandiyan.com](mailto:support@pradappandiyan.com)

## How to get help

Email **support@pradappandiyan.com** and include:

- Android or iOS  
- App version (shown at the bottom of **Profile**)  
- A short description of the issue  
- Screenshots if they help  

We aim to reply within **a few business days**.

## Common tasks

| Task | Where |
| --- | --- |
| Export a backup | Profile → backup / export |
| Restore a backup | Profile → import |
| Wipe local data | Profile → Reset all data |
| Daily reminder | Profile → reminder settings |
| Privacy | [Android policy]({{ site.baseurl }}/replio-gymfit/android/privacy-policy/) · [iOS policy]({{ site.baseurl }}/replio-gymfit/ios/privacy-policy/) |
| Delete data | [Data deletion]({{ site.baseurl }}/replio-gymfit/data-deletion/) |

## What we cannot do remotely

Because Replio GymFit stores data on your device, we cannot recover workouts from our servers. If you need your logs, export a backup before resetting or uninstalling.
